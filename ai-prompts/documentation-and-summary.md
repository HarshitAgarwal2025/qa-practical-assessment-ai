## Overall Approach

I first understood the assessment requirements and planned the work.

Then I prepared the test planning document, created the manual test cases and identified the automation scenarios.

For automation, I reused the existing Playwright framework instead of creating a new one.

Whenever the generated solution did not work as expected, I refined the prompt, updated the code and executed the tests again until the expected result was achieved.

## Key Learnings

- Giving proper project context helped in getting better AI responses.
- Small prompt changes gave better results than writing a completely new prompt every time.
- AI helped save time, but every response still needed review and validation.
- Reusing the existing framework made the implementation easier and more consistent.

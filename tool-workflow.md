# AI Tool Workflow

## AI Tools Used

- ChatGPT
- Cursor AI

## Workflow Followed

### 1. Requirement Analysis

- Used ChatGPT to understand the assessment requirements.
- Broke the work into smaller tasks before starting implementation.

### 2. Test Planning

- Used ChatGPT to prepare the Test Planning and Strategy.
- Reviewed the generated content and refined it before using it.

### 3. Manual Test Design

- Used ChatGPT to generate the initial manual test cases.
- Updated the prompts to improve coverage for positive, negative and edge cases.

### 4. Automation Design

- Used ChatGPT to understand how the existing Prism Playwright framework could be reused.
- Decided to reuse the existing framework instead of creating a new one.

### 5. UI and API Automation

- Used Cursor AI to generate the initial automation.
- Reused existing Page Objects and utilities wherever possible.
- Added only the required files for the Toolshop application.

### 6. Debugging

- Used Cursor AI to analyse automation failures.
- Used ChatGPT to refine prompts and review the suggested fixes.
- Executed the tests after every major change.

### 7. Documentation

- Used ChatGPT to prepare the project documentation and organise the AI prompt history.

## Validation

The AI-generated output was never accepted directly.

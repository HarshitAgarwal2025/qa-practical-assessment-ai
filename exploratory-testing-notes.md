- User Registration

- Registration flow worked as expected.
- New users were able to register successfully.

- Valid users were able to log in successfully.

### 3. Product Search

- Products could be searched using keywords.

### 4. Shopping Cart

- Products could be added and removed from the cart.

- Checkout flow completed successfully with valid details.
